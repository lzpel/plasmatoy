# 自作電源回路と市販計測装置の準備方針

## 背景：パッシェン曲線からの目安

`main.py` の式 V_b = B·pd / (ln(A·pd) − ln(ln(1+1/γ)))（γ = 0.01）による直流・平行平板の理論値。

| 条件 | 値 |
|---|---|
| N₂（A=12, B=342）の pd_min | ≈ 1.05 Torr·cm（139 Pa·cm） |
| d = 20 cm で電圧が最小になる圧力 | ≈ 0.052 Torr（≈ 7 Pa） |
| 最小電圧 V_min（d によらない） | ≈ 357 V |
| γ = 0.1 の場合 | pd_min ≈ 0.55 Torr·cm、V_min ≈ 190 V |
| CCFL 1.5 kV で点火できる圧力の上限（d = 20 cm） | ≈ 0.8 Torr（≈ 110 Pa） |
| フライバック 10 kV で点火できる圧力の上限（d = 20 cm） | ≈ 9 Torr（≈ 1.2 kPa） |

### 考察
- **パッシェン最小は点火電圧の最小であり、発光効率の最適点ではない。** 低圧すぎると壁やシースでの損失が増え、暗くなる。蛍光灯やネオンサインも数 Torr で動いている。
- **「雷っぽいフィラメント」は高い圧力側**（誘電体バリア放電）で出る。低圧では管全体が一様に光るグロー放電になる。
- 最小点（谷底）付近では、d が縮むと谷の左側に入って V_b が急に上がる。マフラーのような接地された金属が近いと放電が引き寄せられるので、圧力をやや高めに設定すると安定しやすい。
- N₂ は振動励起で電力を失いやすく、可視光の効率が悪い。
- **方針：電源が許す範囲で圧力を上げ、見た目で決める。** 理論値は下限の目安にとどめ、実測で詰める。

### ガス
入手しやすさは 空気（無料、N₂ の代用）＞ アルゴン（溶接用の使い切りボンベ、ワインの酸化防止スプレー）＞ 窒素 ＞ ネオン（専門業者）。
まず空気で試し、次にアルゴン（B ≈ 180 で点火電圧が下がる）を使う。充填前に 2〜3 回フラッシングする。

## 方針
1. **計測は市販品で信頼性を確保する**（自作基板の測定値は信用しない）
2. **電源は ESP32 ベースで自作し、周波数と電圧を WiFi から操作する**
3. 市販の計測器を基準にして、自作基板の分圧器を校正する

## 1. 市販計測装置

| 用途 | 機器 | 備考 |
|---|---|---|
| 高電圧波形 | **オシロ用の高電圧プローブ 1000:1、20 kV 級以上** | 中古の Tektronix P6015A（75 MHz）、新品なら Pintek HVP 系や Cal Test CT4028 など |
| 表示と記録 | **LAN/USB で PC から操作できるデジタルオシロ** | Rigol、Owon、Siglent など。Python（pyvisa）でピーク値、実効値、周波数を CSV に記録する |
| 絶対値の確認 | 球ギャップ（IEC 60052） | 球の間隔から放電電圧がわかる。プローブの確認用 |
| 50/60 Hz での点灯電圧（任意） | 中古の耐電圧試験器（AC 0〜5 kV、電流遮断機能付き） | 菊水 TOS 系など。周波数が違うので本番の値とは一致しない |

### 注意
- **テスター用の高電圧プローブ（Fluke 80K-40 など）は 50/60 Hz 専用で、数十 kHz では使えない。**
- プローブの入力容量（数 pF）は 30 kHz で約 2 MΩ 相当になり、10 kV のとき約 5 mA の負荷になる。出力の弱いフライバックでは電圧が下がる。
- オシロのグラウンドは商用電源のアースにつながっている。高電圧側の基準点をそろえる。
- 型番、価格、仕様は購入前に再確認する。

## 2. 自作電源回路（ESP32 版）

```
12V ─┬─[可変降圧DC-DC]─ Vrail(0〜12V) ─┐
     │      ↑ 電圧指令(DAC)               │
     │                                    ▼
     │  ESP32 ──MCPWM(f, duty)──▶ ゲートドライバ ─▶ MOSFET ─▶ HVトランス ─▶ 電極
     │    ▲  ▲                                         │                │
     │    │  └── 一次電流（シャント＋電流アンプ）◀──────┘                │
     │    └───── 出力電圧（1000:1 分圧＋絶縁）◀──────────────────────────┘
     └─ WiFi: Web UI / WebSocket → PC で掃引・ログ(CSV)
```

| ブロック | 内容 |
|---|---|
| 周波数 | ESP32 の MCPWM で 10〜100 kHz を出す。デッドタイムも付けられる |
| 電圧 | 可変の降圧 DC-DC の帰還端子に DAC（MCP4725 など）で電圧を足し込み、電源電圧を変える。出力の振幅はほぼ比例する |
| ドライバ | ローサイドなら TC4420、ハーフブリッジなら IR2110 など |
| 出力電圧の測定 | 100 MΩ と 100 kΩ の分圧器 → 絶縁アンプ（AMC1311 など）→ ADC |
| 点灯の検出 | 一次電流が急に増えたことを検出する（シャント抵抗と INA180 など） |
| 保護 | 過電流のときにハードウェアだけでゲートを止める。物理的な非常停止スイッチで 12V を直接切る |

### 押さえどころ
- フライバックの自己共振で、出力は周波数によって数倍変わる。出力は推定せず、実測した値で制御する。
- 放電は点灯した瞬間に抵抗が急に下がるので、定電圧よりも**電流が制限されること**が重要。
- **自動掃引モード：** 周波数 f を固定して電圧を少しずつ上げ、点灯を検出したら V と f を記録してすぐ下げる。これで周波数・圧力ごとの点灯電圧のマップを取る。

## 進め方
1. 市販のオシロと高電圧プローブをそろえる。今ある 555 とフライバックの回路（C1）で、圧力ごとの点灯電圧を測って記録する
2. ESP32 の開発ボードと市販モジュールでブレッドボード試作する（MCPWM、DC-DC＋DAC、分圧器、Web UI）
3. 掃引ファームウェアを作り、市販プローブを基準に自作分圧器を校正する
4. 構成が固まったら PCB にする（量産版 C2）

## 安全
- 数 kV は致死的。片手で操作し、接地を確実に取り、通電中は触らない。
- リモート操作を基本にし、高電圧の部分には近づかない。
